# MCLA Tracklist Editor (PS3) - технические заметки

Игра: Midnight Club: Los Angeles, BLES00652 (EU), расшифрованный образ, распакованный в папку (`iso_extract.py` берёт
имена из дерева Joliet: в ISO9660 они заглавные, а игра открывает `carchive_*.rpf` строчными, RPCS3 различает регистр).

## Архивы (`PS3_GAME/USRDIR`)
- `carchive_cache.rpf` (2.03 ГБ), `carchive_music.rpf` (0.69 ГБ, 108 треков, dir `music`), `carchive_audio.rpf`
  (1.75 ГБ, заставки конца гонки в dir `8fd900e5`), `carchive_cache2.rpf`. Нет `audlo` (в отличие от X360).
- RPF3 с тем же AES-ключом, что на X360 (`rpf3.py`), папка платформы - хэш `0173b0cf` вместо `x360`.
  Ресурсы RSC сжаты zlib (не LZX). Смещения 31-битные: архив не больше 2 ГБ (`rpf3_rebuild.py`).
- `game.dat` и `sounds.dat` (cache, `audio/<ps3>/config`) побайтно равны X360-версии: плейлисты, жанры, гараж,
  списки заставок - та же логика (`mcla_model.py`, `addsong.py`, `sounds_rebuild.py`, `gamedat_rebuild.py`).
- Текстовые банки (dir `1b2d32db` в cache): основной `5fd0e138` (= `e7781e54`), South Central `306ae60f` (= `af1b1257`);
  формат как на X360. South Central на этом диске активен (Hip Hop: 13 + 4 песни).

## Трек (`mp3_track.py`, `mp3_encode.py`)
Раскладка как у X360-треков, внутри вместо XMA - MPEG-1 Layer III, моно, без бит-резервуара (main_data_begin = 0 у всех
кадров оригинала), 44.1 кГц (8 заставок - 48 кГц).
- Заголовок: `[0, hdr_size, nblocks, 0x20000, 0, 0, 0x30, 0, hdr_size, 2, 0, first_block, 0, 0, id0, sec0, 0, sec0, id1,
  sec1]` (BE), потом на поток `[0, 0, id, байты, сэмплы, 0xffffffff, rate<<16|low, 0x100, 0, 0x38, 1152, кадры, w12, w13]`
  + u16 размеры кадров (у SC-треков и `a1617e73` таблицы нет, секция 0x38). Потом (старт блока, rate) на блок,
  выравнивание до 0x800. id потоков = joaat(<wave>_LEFT/_RIGHT), по возрастанию.
- Блок 0x20000: заголовок 0x800 `[0, 0x18, 0, 0x48, 0, 0x48, 0, cnt0, skip0, n0, frames0, bytes0, cnt0, cnt1, skip1, n1,
  frames1, bytes1]` + таблицы `[base, c-1, c, ..., E-1]` по каждому пакету; остаток заголовка - байты предыдущего блока.
  "Пакет" = жадная группа целых кадров до 0x800 байт; область потока = cnt*0x800, кадры подряд, нули в конце.
  62 пакета на блок, пакет добавляется каналу, у которого меньше кадров; канал, что впереди, повторяет последний пакет
  в следующем блоке; конец отстающего канала T = 1152*кадры, опережающего floor(f32(T)*f32(1.00001)).
- Проверка: `regen_test.py` / `regen_eor.py` собирают все 108 песен и 84 двухканальные
  заставки оригинала байт в байт (с концами блоков оригинала; наша формула конца отличается на ±1 сэмпл в ~10 %).
- Кодирование: ffmpeg + libmp3lame, `-reservoir 0 -write_xing 0`, каждый канал отдельно моно, `-q:a 3` ≈ оригинал.

## Скорость
- Оглавления RPF3 (16 x AES-256 ECB) расшифровываются системным AES Windows (`aes_fast.py`, BCrypt через ctypes;
  вне Windows - `aes_pure.py`): открытие игры ~1.3 с вместо ~17 с.
- Кодирование: один запуск ffmpeg на песню (оба канала сразу), до 8 песен/заставок параллельно до записи архивов
  (`Project._prefetch_encodes`); архивы побайтно те же, что при последовательной сборке.

## Платформа
`mcla_platform.py`: всё, что отличается от X360 (пути, архивы, хэши банков, кодек). В этой программе включена только
PS3 (`PLATFORMS = (PS3(),)`).
