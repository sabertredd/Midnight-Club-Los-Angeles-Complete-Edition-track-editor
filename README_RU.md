# Midnight Club: Los Angeles — редактор саундтрека

Неофициальные инструменты для правки саундтрека **Midnight Club: Los Angeles**:

* **Xbox 360** — Complete Edition (`xbox360/`)
* **PlayStation 3** — BLES00652 (`ps3/`)

Файлов игры, ключей шифрования и программ Microsoft здесь нет. Нужна своя копия игры.

## Возможности

* плейлисты: порядок, жанр, удаление песен, добавление своих песен (любой формат, который читает ffmpeg)
* замена звука любой песни, правка названий
* переименование 7 жанров (6 языков)
* заставки конца гонки (музыка на экране победы): автоматический отрывок или свой файл, прослушивание по кругу
* музыка гаража и списки заставок следуют за плейлистами, удалённые песни там больше не играют
* замена музыки на тусовках (6 фрагментов)
* освобождение места удалённых песен (каждый архив ограничен 2 ГБ)
* нормализатор громкости (отдельная программа) под уровень оригинальных песен
* утилита удаления резервных копий `.rpf.bak`
* черновик сохраняется автоматически, а файл рядом с папкой игры помнит, что было изменено

## Папки

| Папка | Что внутри |
|---|---|
| `bin/` | готовые программы для Windows: редактор, нормализатор и очистка копий (Xbox 360), редактор для PS3 |
| `xbox360/MCLA_Editor/` | исходники на Python; `README.txt` — подробная инструкция; `mcla_unpack.py` — распаковщик архивов |
| `ps3/MCLA_Editor_PS3/` | исходники редактора для PS3 и его `README.txt` |
| `docs/` | описание форматов: архивы RPF3, `game.dat`, `sounds.dat`, текстовые банки, раскладка треков XMA / MP3 |
| `names/` | найденные имена файлов в архивах и статистика |

## Что нужно

* Windows 10/11. Программам из `bin/` больше ничего не нужно, исходникам нужен Python 3.10+ с tkinter.
* **ffmpeg** — чтение аудиофайлов, прослушивание, громкость.
* **Звук Xbox 360:** XMA-кодировщик Microsoft XMAENCODE из Xbox 360 SDK. Он не входит в комплект, и распространять его
  нельзя. Имя файла может быть любым (`xmaencode.exe`, `xmaencode2008.exe` и т.п.). Редактор сам ищет `*xma*enc*.exe`
  рядом с собой и в папке SDK, либо путь указывается в *Audio settings*. Кодировщик должен выдавать XMA1:
  `xma2encode.exe` пишет XMA2 и не подходит.
* **Звук PS3:** MP3 кодирует сам ffmpeg (LAME), больше ничего не нужно.

## Первый запуск: ключ архивов

Архивы игры (`.rpf`) зашифрованы. Ключ принадлежит игре и **в программы не входит**. При первом открытии папки игры
программа один раз спросит его. Есть два способа:

1. **Ввести** — 64 шестнадцатеричные цифры.
2. **Найти** — указать расшифрованный и распакованный исполняемый файл самой игры. Программа ищет в нём ключ и
   проверяет каждый вариант на ваших архивах.
   * Xbox 360: `default.xex` после, например, `xextool -e u -c u default.xex`
   * PS3: `EBOOT.BIN`, расшифрованный в RPCS3 (*Utilities → Decrypt PS3 Binaries* → `EBOOT.elf`)

Ключ сохраняется в `mcla_rpf_key.txt` рядом с программой. Этот файл никому не передавайте.

## Важно

* **Работайте с копией папки игры.** «Save to the current folder» сохраняет первый оригинал каждого изменённого
  архива как `*.rpf.bak`. «Build test game folder» собирает новую папку с жёсткими ссылками на неизменённые файлы.
* **Оставляйте хотя бы одну песню в каждом жанре.** Если сохранение игры помнит жанр, который стал пустым, игра на
  настоящей Xbox 360 зависает при загрузке, а на PS3 (RPCS3) — вылетает.
* Игра берёт набор архивов `audio + music + cache` или `audlo + cache`, поэтому редактор меняет `music` и `audlo`
  вместе.
* Xenia берёт `audlo + cache`, поэтому музыки на тусовках (она только в `audio.rpf`) там нет даже в оригинале.
  Проверяйте её на консоли.
* Файлы рядом с папкой игры (`<папка>.mcla_changes.json`, `<папка>.mcla_draft.json`) нужны только редактору, на
  консоль их не копируйте.

## Что проверено

* Xbox 360: в Xenia и на настоящей консоли. Проверены плейлисты, названия, жанры, добавленные и заменённые песни,
  гараж, заставки, музыка на тусовках, плотная пересборка архивов, освобождённые песни и громкость.
* PS3: в RPCS3 и на настоящей PS3 (плейлисты, жанры, заменённые и добавленные песни, музыка на тусовках). Заставки
  конца гонки на PS3 пока не проверены.
